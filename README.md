# Proyecto 1: Altavoz Inteligente Compacto (Raspberry Pi Zero 2 W)

Fase actual: Pruebas de concepto y desarrollo base.

## Hardware Utilizado:
- SBC: Raspberry Pi Zero 2 W
- Driver: Dayton Audio DMA45-4 (1.8")
- DAC/Amp: MAX98357A I2S
- LEDs: WS2812B Neopixel
- Carcasa: Búho Robotizado (Tamaño compacto)
